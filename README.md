About the Project

FOUND by Alrect is an open-source project dedicated to collecting, documenting, and studying Roblox scripts, including scripts that have been deobfuscated for code analysis and educational purposes.

This repository is not a script executor, a commercial tool, or an automated hacking service. It is a code archive built around the idea that understanding a script is just as important as finding it.

The project aims to make script research more transparent by organizing available code, preserving useful findings, and providing context wherever possible.

Why FOUND?

Scripts can be difficult to understand when their original code has been obfuscated, compressed, or stripped of meaningful names.

FOUND exists to document that process and make the resulting code easier to inspect, learn from, and maintain.

Every contribution to this archive should prioritize readability, useful documentation, and respect for the original creators.

What You'll Find Here

- Roblox Lua Scripts — collected scripts organized for easier reference.
- Deobfuscated Code — recovered or reconstructed source code when available.
- Code Research — notes about script structure, behavior, and relevant findings.
- Documentation — explanations and context to help readers understand the contents.
- Open-Source Contributions — improvements, corrections, and additional documentation from the community.

The contents may change as the repository develops throughout 2026–2027.

Deobfuscation & Code Integrity

Deobfuscation does not always restore the exact original source code.

Depending on the available material, some results may contain renamed variables, reconstructed control flow, missing comments, or unresolved dependencies.

For transparency:

- Original source code and deobfuscated output should be distinguished whenever possible.
- Unverified findings should not be presented as confirmed facts.
- Known limitations and dependencies should be documented.
- Code should be reviewed before being described as safe or functional.

The goal is not merely to make code readable, but to help readers understand what is known, what has changed, and what remains uncertain.

Responsible Use

This repository is intended for code analysis, education, and legitimate development.

Please respect Roblox's Terms of Use, the rights of script authors, and the licenses attached to third-party code.

Do not use this project to steal accounts, collect credentials, distribute malicious code, bypass access controls, or disrupt other players' experiences.

Only publish material that you have the right to share. When working with third-party scripts, preserve available attribution and licensing information.

Contributing

Contributions are welcome when they improve the quality and transparency of the archive.

Before submitting a contribution:

1. Explain what the script or finding contains.
2. Include relevant source attribution when available.
3. Document the deobfuscation process and any known limitations.
4. Avoid uploading private, stolen, or harmful material.
5. Keep filenames, folder structures, and documentation consistent.

A useful contribution does not have to be complicated. Sometimes, a clear explanation or a corrected piece of documentation makes a real difference.
